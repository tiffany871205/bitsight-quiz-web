# Bitsight Learning Lab｜資安產品題庫與模擬考試

一個以繁體中文製作的 **Bitsight 互動式學習網站**，整合 **400 題題庫搜尋**與**四選一模擬考試**，適合資安產品知識複習、教育訓練及 PM 客戶應答練習。

### 🌐 立即使用

**[前往 Bitsight Learning Lab](https://tiffany871205.github.io/bitsight-quiz-web/)**

網站已透過 GitHub Pages 公開部署，使用瀏覽器即可開啟，無須安裝軟體或登入。

## 主要功能

### 🔎 題庫搜尋

- 收錄 **400 題** Bitsight 相關題目。
- 可搜尋題目、答案、解析及專有名詞。
- 支援主題分類與題庫來源篩選。
- 點開題目即可查看答案及解析。

### 📝 模擬考試

- 四選一選擇題，可依分類練習。
- 自訂題數：10、20、50、100 題或全部題目。
- 隨機出題、自由切換前後題目。
- 交卷後顯示成績、正確答案與逐題解析。
- 自動記錄錯題，支援錯題重練。

### 📱 使用體驗

- 響應式網頁設計，支援電腦與手機。
- 不需註冊帳號。
- 錯題與最近一次測驗成績儲存在目前瀏覽器中，不會跨裝置同步；清除網站資料後也會消失。

## 題庫內容

涵蓋 Bitsight 產品定位、EASM／SPM、CM／TRM、VRM、Beacon、TMH、平台操作、權限管理、風險向量、評分機制、資安技術名詞，以及客戶情境與主管口試題。

題庫資料整理自專案的 `Bitsight_主管考試與實務題庫_Notion版.md`。網站使用 `questions.json` 儲存題目、正解及既有解析。

> **注意：** 本網站為非官方學習工具，並非 Bitsight 官方考試。模擬考試的正確答案沿用原始題庫，另外三個選項由其他題目的答案自動產生，僅供練習；部分題目原本沒有獨立解析。產品功能、授權及操作方式應以實際合約、平台版本與官方文件為準。

**2026-10-19 選項品質改善：** 已個別編寫 95 題的干擾選項，其餘 305 題仍待審核。模擬考試預設只使用已個別編寫選項的題目；如要練習全部題目，可勾選「包含未審核選項」。搜尋模式仍可查看完整 400 題。這是選項品質的初步篩選，不代表正確答案已逐題獲原廠認證。詳見 [QUALITY_AUDIT.md](QUALITY_AUDIT.md)。

## 技術與專案結構

網站以 **HTML、CSS、JavaScript** 製作，不需要後端服務或額外的套件安裝，並使用 **GitHub Pages** 部署。

```text
bitsight-quiz-web/
├── index.html       # 網站頁面
├── styles.css       # 介面與響應式樣式
├── app.js           # 搜尋、考試、計分及錯題功能
├── questions.json   # 400 題題庫資料
└── README.md        # 專案說明
```

## 本機預覽（開發用途）

在此專案目錄執行：

```bash
python3 -m http.server 8080
```

接著開啟 `http://localhost:8080`。由於瀏覽器對本機檔案讀取的限制，不建議直接以 `file://` 開啟 `index.html`。

## 資料與隱私

作答紀錄與錯題清單僅儲存在使用者瀏覽器的 `localStorage`。網站不需要登入，也沒有加入第三方分析追蹤程式。若原始 Markdown 題庫有更新，網站的 `questions.json` 也需要同步更新。

## 學習紀錄與備份

網站使用瀏覽器 `localStorage` 保存待複習錯題、曾經答錯的題目，以及每次交卷的完整題目與作答紀錄。即使題目後來答對，歷史錯題仍會保留。模擬考試設定頁提供 **匯出學習紀錄 JSON** 與 **匯入學習紀錄 JSON**；匯入會取代目前裝置的紀錄，建議事先匯出備份。資料不會自動跨裝置同步。

## 解析與延伸閱讀說明

題目頁面與交卷檢討提供相關資料連結。原始題庫未附解析的 50 題已依既有答案補充簡要解說，並標示為「依原題答案補充（待逐題查證）」。其他題目保留原始題庫解析。連結主要是官方說明中心或相關技術標準，**並非逐題查核過的直接證據**；涉及產品功能或授權時仍應核對官方文件與實際合約。

## 2026-10-19 學習紀錄更新

- 新增由題目內容衍生的穩定 UID；錯題與曾答錯紀錄改存 v2，首次載入會由 v1 題號自動轉換。
- 未作答與答錯分開計算，未作答不會自動加入錯題。
- 新增依分類統計累積作答正確率（僅統計有作答的題目）。
- 既有歷史成績仍保留在瀏覽器；匯入支援舊版與新版 JSON。
- 題目標示來源查證狀態；「延伸閱讀」不等同逐題官方證實。
- 本次未批次自動替換答案或錯誤選項，避免在未逐題人工查證前引入錯誤。

## 題目品質改進

## 全題庫選項一致性檢查

- 全部題目均已檢查四個選項互不重複、正確答案索引一致。
- 自動將其他相關知識點的答案轉為干擾選項；**此為候選選項，不代表完成逐題語意／原廠查證**，使用時應參考答案解析及來源。
- 品質審核清單見 `QUALITY_AUDIT.md`。
